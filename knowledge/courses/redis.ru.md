Redis держит данные в памяти и отвечает на большинство команд намного быстрее чем за миллисекунду. Такая скорость меняет само представление о том, на что годится хранилище данных. Реляционная база остаётся источником истины, а Redis берёт на себя работу, которая иначе замедлила бы базу: повторяющиеся чтения, счётчики запросов, кратковременную координацию между серверами и сообщения, которые важны только прямо сейчас.

Курс знакомит с Redis как с хранилищем «ключ — значение», у которого есть полезные структуры данных, а затем применяет его к шаблонам, чаще всего встречающимся в распределённых системах. Вся работа идёт в `redis-cli`, поэтому каждый пример — обычная команда Redis, а не код на каком-то одном языке. Уроки исходят из одного экземпляра Redis и отдельно отмечают, где Redis Cluster меняет ответ.

## Установка Redis на macOS

Необходимый инструмент: [Homebrew](https://brew.sh/).

Установите сервер и его клиент командной строки:

```sh
brew install redis
```

Запустите Redis сейчас и сделайте так, чтобы он автоматически запускался при входе в систему:

```sh
brew services start redis
```

Убедитесь, что сервер отвечает:

```sh
redis-cli PING
```

Он ответит `PONG`, и можно переходить к первому уроку.

## Чему вы научитесь

- Где место Redis рядом с надёжной базой данных и где он оказывается не тем инструментом.
- Как запустить Redis на macOS и исследовать его из `redis-cli`.
- Какой тип данных требует каждая задача и как проектировать ключи, в которых можно разобраться и много позже.
- Как истечение срока жизни и вытеснение превращают Redis в кэш, а не в хранилище, которому можно доверить данные.
- Как безопасно кэшировать часто читаемые данные, включая инвалидацию и защиту от лавины запросов.
- Как ограничивать частоту запросов с помощью счётчика и почему простая версия пропускает всплески.
- Как координировать работу нескольких серверов с помощью блокировки с истекающим сроком и чего такая блокировка обещать не может.
- Как рассылать сообщения в реальном времени и когда доставки по принципу «отправил и забыл» недостаточно.
