Этот курс учит сохранять данные PostgreSQL корректными, а запросы — эффективными, даже когда с базой одновременно работают несколько сеансов. Сначала вы освоите терминальный клиент `psql`, схемы и управление доступом. Затем перейдёте к транзакциям и внешним ключам, научитесь измерять планы запросов и проектировать индексы. Заключительные уроки посвящены версиям строк, VACUUM, блокировкам, JSONB и резервным значениям, которые подставляет `COALESCE`.

В каждом уроке есть примеры SQL и локальное упражнение, которое помогает на практике изучить, что гарантирует та или иная возможность и чего она стоит.

## Установка и запуск PostgreSQL на macOS

Понадобится [Homebrew](https://brew.sh/).

Установите [PostgreSQL 18](https://formulae.brew.sh/formula/postgresql%4018):

```sh
brew install postgresql@18
```

Homebrew не добавляет команды этой версии в путь поиска оболочки автоматически. Пропишите их в конфигурацию zsh:

```sh
echo 'export PATH="$(brew --prefix postgresql@18)/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

Запустите PostgreSQL сейчас и настройте автоматический запуск при входе в систему:

```sh
brew services start postgresql@18
pg_isready
```

Создайте базу данных для курса и откройте её в `psql`:

```sh
createdb postgresql_course
psql postgresql_course
```

В приглашении `psql` проверьте подключение и выйдите:

```text
\conninfo
\q
```

Чтобы впоследствии остановить PostgreSQL и убрать его из служб, запускаемых при входе, выполните:

```sh
brew services stop postgresql@18
```
