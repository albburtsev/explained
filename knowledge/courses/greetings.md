Every programming journey needs a small, friendly beginning. This course uses the classic **Hello, World!** program to introduce the rhythm of reading, running, and changing code.

## What you will learn

- How to print text from a TypeScript program.
- How to run the program with Node.js.
- How a tiny edit changes the program's output.
