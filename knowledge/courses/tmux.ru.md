Терминальный мультиплексор хранит оболочки и долгие процессы независимо от конкретного окна терминала. Курс начинается с tmux и его модели из сессий, окон, панелей и клавиши-префикса, а затем переносит те же идеи устойчивого терминала на Herdr — рабочую среду, созданную под агентов для программирования.

Вторая часть курса посвящена Orca — настольному приложению для разработки вместе с ИИ-агентами. Orca запускает каждого агента в собственном git worktree, поэтому несколько агентов могут работать параллельно, не задевая чужих изменений. Вы проведёте задачу с GitHub весь путь до смерженного пулл-реквеста и освоите инструменты, которые Orca выстраивает вокруг этого процесса.

## Установка tmux, Herdr и Orca на macOS

Если вы пользуетесь Homebrew, установите инструменты до начала уроков. Выполните эти команды на каждом хосте с macOS, где будут жить ваши сессии:

```sh
brew install tmux
brew install herdr
brew install --cask stablyai/orca/orca
```

Убедитесь, что команда tmux доступна:

```sh
tmux -V
```

Все вспомогательные библиотеки, которые нужны этим формулам, Homebrew установит сам — отдельно ставить их не нужно.

## Чему вы научитесь

- Устанавливать и запускать tmux, работать с сессиями, окнами и панелями, пользоваться основными горячими клавишами, сохранять удалённую работу живой и отличать отсоединение от выхода.
- Устанавливать Herdr и работать в нём, перемещаться между его рабочими пространствами, вкладками и панелями, присматривать за несколькими ИИ-агентами для программирования и заново подключаться к работе, запущенной на удалённом хосте.
- Понимать, как Orca организует репозитории, worktree и агентов, и настраивать его для работы с GitHub, агентами и рабочими пространствами.
- Проводить задачу с GitHub в Orca до смерженного пулл-реквеста и по пути проверять дифф, написанный агентом.
- Запускать нескольких агентов на одну задачу и координировать их с помощью Orca CLI.
- Работать над интерфейсом во встроенном браузере Orca и в режиме Design Mode, а также запускать агентов в удалённых worktree по SSH.
