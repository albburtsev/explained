`Vim` — гибко настраиваемый `модальный` текстовый редактор, созданный для того, чтобы писать и править любой текст как можно эффективнее. В большинстве Unix-систем и в macOS он есть под именем `vi`, поэтому доступен почти везде, где есть терминал. Текущая стабильная версия — Vim 9.2. Курс знакомит с редактором, а затем шаг за шагом прививает практические навыки, с которыми редактировать файлы можно уверенно.

## Установка Vim

Возможно, Vim у вас уже установлен. Проверить это можно так:

```sh
vim --version
```

В macOS терминальная версия уже есть под именем `vi`. Чтобы установить последний выпуск через [Homebrew](https://formulae.brew.sh/formula/vim), выполните:

```sh
brew install vim
```
