`OpenSpec` is a file-based planning layer that gives you and a coding agent a shared, reviewable plan before implementation begins. This course introduces the workflow, shows how to use it with an agent, and then explains the commands and files that keep each change organized.

## What you will learn

- What OpenSpec solves and how to install it on macOS.
- How to guide a change from `exploration` to implementation and `archive`.
- How the `CLI`, `planning artifacts`, `specifications`, and `agent integrations` fit together.
