`Манифест веб-приложения` (web app manifest) — это JSON-файл, в котором приложение описано для браузера и операционной системы. Он задаёт название, иконки, цвета, стартовую страницу и вид окна. Браузер обращается к манифесту, когда решает, как установить и запустить приложение. На саму страницу манифест никак не влияет: в обычной вкладке она выглядит точно так же, как раньше.

В этом уроке вы добавите манифест в проект `daily-quote/`. Установке приложения посвящён следующий урок.

## Иконки

Приложению нужны две квадратные иконки в формате PNG: 192×192 и 512×512 пикселей. Пока обоих размеров нет, Chrome не предложит установить приложение.

Возьмите любое квадратное изображение, например `logo.png`, и положите его в папку проекта. Затем сделайте из него иконки с помощью `sips` — встроенной в macOS утилиты для работы с изображениями:

```sh
mkdir icons
sips -s format png -z 192 192 logo.png --out icons/icon-192.png
sips -s format png -z 512 512 logo.png --out icons/icon-512.png
```

Параметр `-z` принимает сначала высоту, а затем ширину. Благодаря `-s format png` результат сохраняется в PNG, так что исходник может быть и в JPEG. Берите изображение шириной не меньше 512 пикселей, чтобы большая иконка осталась чёткой.

## Пишем манифест

Создайте в корне проекта, рядом с `index.html`, файл `manifest.webmanifest`:

```json
{
  "name": "Daily Quote",
  "short_name": "Quote",
  "icons": [
    {
      "src": "icons/icon-192.png",
      "sizes": "192x192",
      "type": "image/png"
    },
    {
      "src": "icons/icon-512.png",
      "sizes": "512x512",
      "type": "image/png"
    }
  ],
  "start_url": "/",
  "scope": "/",
  "display": "standalone",
  "theme_color": "#1e3a5f",
  "background_color": "#ffffff"
}
```

Это обычный JSON, поэтому комментарии и запятые после последнего элемента в нём недопустимы. Расширение `.webmanifest` рекомендует спецификация, но файл с именем `manifest.json` тоже подойдёт.

## Что означает каждое поле

- `name` — полное название приложения. Система показывает его в предложении установить приложение, в заголовке окна и в списках программ.
- `short_name` — сокращённое название для мест, где мало пространства, например для подписи под иконкой.
- `icons` — список файлов иконок. В `src` указан путь, в `sizes` — размер в пикселях, в `type` — формат файла. Для каждого места система сама выбирает подходящий размер.
- `start_url` — страница, которая открывается при запуске приложения. Значение `/` обозначает корень сайта, поэтому приложение откроет `index.html`.
- `scope` — `область действия` приложения, то есть набор адресов, которые ему принадлежат. Здесь это `/`, то есть весь сайт, так что и `index.html`, и `about.html` входят в приложение. Если пользователь перейдёт по ссылке за пределы области действия, в окне приложения появятся элементы управления браузера, и станет видно, что приложение осталось позади.
- `display` — вид окна. При значении `standalone` приложение открывается в собственном окне без адресной строки. Остальные варианты — `fullscreen`, `minimal-ui` и `browser`; последний действует по умолчанию и открывает обычную вкладку. Если браузер не поддерживает выбранное значение, он переходит к следующему по цепочке `fullscreen` → `standalone` → `minimal-ui` → `browser`.
- `theme_color` — цвет интерфейса приложения, например заголовка его окна. Тег `<meta name="theme-color">` на странице переопределяет этот цвет для неё.
- `background_color` — цвет, которым заливается окно приложения, пока страница загружается и CSS ещё не применён. Затем в дело вступают собственные стили страницы. Укажите тот же цвет, что и у фона страницы, — тогда пользователь не заметит вспышки. В `style.css` фон не задан, страница белая, поэтому в примере стоит `#ffffff`.

Относительные адреса в манифесте, такие как `icons/icon-192.png`, отсчитываются от адреса самого манифеста, а не страницы. Манифест лежит в корне проекта, поэтому пути к иконкам ведут в папку `icons/`.

Значение `start_url` должно находиться внутри `scope`. Иначе браузер проигнорирует указанную область действия и, оставшись без корректного `scope`, возьмёт в качестве неё папку, в которой находится `start_url`.

## Подключаем манифест к странице

Браузер находит манифест по элементу `<link>` в разделе `<head>` страницы. Добавьте его в `index.html`, рядом со ссылкой на таблицу стилей:

```html
<link rel="manifest" href="/manifest.webmanifest">
```

Ту же строку добавьте в `about.html`: каждая страница подключает манифест самостоятельно. Без этой ссылки браузер не узнает, что страница относится к приложению, и не сможет предложить установить его с этой страницы.

## Проверяем результат

Запустите сервер из папки `daily-quote/`:

```sh
npx http-server -c-1
```

Откройте `http://localhost:8080` в Chrome. Вызовите DevTools сочетанием `Cmd+Option+I` и перейдите в **Application** → **Manifest**. На этой панели видны название, стартовый адрес, цвета и обе иконки. Если какое-то поле задано неверно или иконка не загрузилась, панель покажет предупреждение.

Панель может также посоветовать добавить поле `id`. Оно необязательно: без него браузер определяет приложение по `start_url`.

Safari тоже читает манифест. Когда вы добавляете сайт в Dock, он берёт из манифеста название, стартовый адрес, вид окна и цвет темы.
