В двух предыдущих уроках вы научились перемещаться по тексту и редактировать его, пользуясь поведением Vim по умолчанию. Но настройки по умолчанию — лишь отправная точка: Vim создан для того, чтобы его настраивали, и почти всё в нём — от номеров строк до поведения поиска — управляется `опциями`, внутренними переключателями, которые можно включить, выключить или задать им значение. В этом уроке вы соберёте любимые настройки в небольшом конфигурационном файле, чтобы каждый сеанс Vim начинался так, как вам удобно.

## Файл vimrc

Файл `vimrc` — это обычный текстовый файл, который Vim читает один раз при запуске. Каждая его строка — одна команда режима Command-line, та самая, которую вы набрали бы в Vim после `:`, только записанная без двоеточия. Vim выполняет строки по порядку, прежде чем показать первый файл. Строка, начинающаяся с `"`, — комментарий: Vim её пропускает, так что в файле можно оставлять заметки для себя.

В macOS Vim ищет ваш личный vimrc в фиксированном списке мест и читает только первый найденный файл:

- `~/.vimrc`
- `~/.vim/vimrc`

Если vimrc нет вовсе, Vim загружает вместо него файл `defaults.vim`, который включает несколько разумных настроек, например подсветку синтаксиса и определение типа файла, — поэтому свежеустановленный Vim уже выглядит вполне прилично. Как только вы создадите собственный vimrc, `defaults.vim` перестанет загружаться, и эти настройки придётся хранить в вашем файле. Если хотите сохранить встроенные настройки Vim как основу, официальная документация советует поместить `unlet! skip_defaults_vim` и `source $VIMRUNTIME/defaults.vim` в начало файла.

## Стартовый vimrc

Откройте файл командой `vim ~/.vimrc` — Vim создаст его при сохранении — и добавьте такой стартовый набор:

```vim
" Color the text according to the language of the file
syntax on

" Show line numbers
set number

" Indent with four columns and use spaces instead of tab characters
set tabstop=4
set shiftwidth=4
set expandtab
set autoindent

" Search without case, unless the pattern contains a capital letter
set ignorecase
set smartcase

" Show matches while typing and highlight all of them
set incsearch
set hlsearch
```

Каждая строка настраивает одну опцию:

- `syntax on` включает `подсветку синтаксиса`: ключевые слова, строки и комментарии окрашиваются в зависимости от языка файла. Раз `defaults.vim` больше не выполняется, без этой строки в vimrc пропадут цвета, к которым вы, возможно, уже привыкли.
- `number` выводит номер перед каждой строкой, и так гораздо проще понять, где в файле вы находитесь.
- `tabstop=4` отображает символ табуляции шириной в четыре колонки.
- `shiftwidth=4` задаёт отступ в четыре колонки.
- `expandtab` вставляет пробелы вместо настоящего символа табуляции, когда вы нажимаете `Tab` в режиме Insert.
- `autoindent` копирует отступ текущей строки, когда вы начинаете новую.
- `ignorecase` заставляет поиск не различать прописные и строчные буквы.
- `smartcase` снова включает учёт регистра, как только в шаблоне поиска появляется заглавная буква; эта опция работает только вместе с `ignorecase`.
- `incsearch` переходит к первому совпадению, пока вы ещё набираете запрос.
- `hlsearch` подсвечивает все совпадения, так что поиск через `/` сразу высвечивает каждое вхождение.

## Сначала попробуйте опции на лету, затем примените файл

Чтобы проверить опцию, редактировать файл не обязательно: в режиме Command-line команда `:set` действует сразу, в пределах текущего сеанса. Для повседневной работы хватает четырёх форм:

- `:set number` включает опцию
- `:set nonumber` выключает её
- `:set number!` переключает её
- `:set number?` показывает её текущее значение

Изменения, сделанные таким образом, исчезают при выходе из Vim, а строки из vimrc загружаются при каждом запуске. Отредактировав файл, примените его к уже запущенному Vim без перезапуска — для этого файл нужно перечитать, в терминологии Vim это называется `source`: `:source $MYVIMRC`. Vim хранит путь к найденному vimrc в переменной `$MYVIMRC`, поэтому команда перезагрузит ваш файл, где бы он ни лежал. Перезапуск Vim тоже подойдёт.

## Стартовые опции коротко

| Цель | Строки vimrc |
| --- | --- |
| Раскрашивать текст по языку | `syntax on` |
| Показывать номера строк | `set number` |
| Делать отступ в четыре пробела | `set tabstop=4`, `set shiftwidth=4`, `set expandtab` |
| Сохранять отступ на новых строках | `set autoindent` |
| Искать без учёта регистра, пока не введена заглавная буква | `set ignorecase`, `set smartcase` |
| Показывать совпадения при наборе и подсвечивать все | `set incsearch`, `set hlsearch` |

## Попрактикуйтесь в настройке

1. Откройте vimrc командой `vim ~/.vimrc` и нажмите `i`, чтобы войти в режим Insert.
2. Наберите стартовый набор из примера выше или, для минимального начала, только `syntax on` и `set number`.
3. Нажмите `Esc`, сохраните файл командой `:w` и перечитайте его командой `:source $MYVIMRC`. Номера строк появятся сразу.
4. Откройте любой файл, начните поиск через `/` и посмотрите, как совпадения подсвечиваются прямо во время набора.
5. Попробуйте формы для работы на лету: `:set nonumber` скрывает номера, `:set number?` сообщает текущее значение, а `:set number!` возвращает номера обратно.

Когда какая-то опция окажется полезной, перенесите её в файл, чтобы она пережила следующий перезапуск. Опций у Vim на сотни больше, чем поместилось в этот урок: их можно просмотреть командой `:options`, прочитать о любой из них через `:help`, например `:help 'number'`, или изучить [онлайн-документацию по опциям](https://vimhelp.org/options.txt.html).

С собственным vimrc все три части курса сложились воедино: вы понимаете режимы, пальцы помнят основные горячие клавиши, а Vim теперь запускается настроенным так, как вам нравится.
