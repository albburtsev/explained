`psql` — терминальный клиент PostgreSQL. Он отправляет SQL-операторы на сервер и показывает результаты. **SQL** — язык, на котором запрашивают и изменяют данные в базе. Кроме того, у `psql` есть собственные команды для просмотра объектов и управления сеансом.

Прежде чем начать, выполните настройку macOS из обзора курса. Она устанавливает клиент, запускает локальный сервер и создаёт базу данных `postgresql_course`.

## Подключение из оболочки

Откройте Terminal и подключитесь к базе данных курса:

```sh
psql -d postgresql_course
```

При локальном подключении `psql` может воспользоваться Unix-сокетом — каналом связи, который работает только в пределах одной машины. В этом случае в качестве роли базы данных берётся ваше имя пользователя macOS. **Роль** — это учётная сущность, с помощью которой PostgreSQL управляет доступом. Параметр `-d` выбирает базу данных.

Для удалённого сервера замените эти примерные значения его параметрами подключения:

```sh
psql -h db.example.com -p 5432 -U app_user -d app_database
```

Параметры задают хост сервера, порт, роль базы данных и саму базу. Обычно PostgreSQL слушает порт `5432`, но сервер может быть настроен и на другой. Если для аутентификации нужен пароль, пусть `psql` запросит его сам: не вписывайте пароль прямо в команду оболочки, иначе он может остаться в истории команд.

После успешного подключения в приглашении появляется имя текущей базы данных:

```text
postgresql_course=>
```

В стандартном приглашении `=>` означает обычную роль, а `=#` — суперпользователя. Суперпользователь обходит почти все проверки доступа. Локальная установка обычно создаёт именно суперпользователя; приложения же должны подключаться под обычными ролями.

Проверьте, куда подключён сеанс:

```text
\conninfo
```

Текущий контекст можно узнать у сервера и средствами SQL:

```sql
SELECT
  current_database() AS database,
  current_user AS role,
  current_schema() AS schema;
```

## SQL и команды psql

В приглашении `psql` можно вводить два вида команд:

- **SQL-операторы** отправляются в PostgreSQL и обычно завершаются точкой с запятой.
- **Метакоманды psql** начинаются с обратной косой черты, обрабатываются самим клиентом и точкой с запятой не завершаются.

SQL-оператор может занимать несколько строк. Пока не введена завершающая точка с запятой, приглашение меняется на форму продолжения, например `postgresql_course->`. Если вы начали не тот оператор, не доводите его до конца, а очистите буфер ожидающего запроса:

```text
\r
```

## Навигация по базам данных и схемам

Выведите список баз данных на сервере:

```text
\l
```

Переключитесь на другую базу, не выходя из `psql`, а затем вернитесь к базе курса:

```text
\c postgres
\c postgresql_course
```

Каждая команда `\c` открывает новое подключение. Если есть хоть малейшее сомнение, какая база или роль сейчас активна, выполните после неё `\conninfo`.

Схемы группируют именованные объекты внутри базы данных. Выведите список схем и таблиц, видимых через путь поиска схем текущего сеанса:

```text
\dn
\dt
```

В пустой базе `\dt` сообщит, что отношений не найдено. **Таблица** хранит записи в виде строк с именованными столбцами. Создайте таблицу и вставьте в неё строку:

```sql
CREATE TABLE terminal_notes (
  id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  body text NOT NULL,
  created_at timestamptz NOT NULL DEFAULT now()
);

INSERT INTO terminal_notes (body)
VALUES ('psql is connected')
RETURNING id, body, created_at;
```

Значение `id` генерируется автоматически и идентифицирует каждую строку. Столбец `body` обязан содержать значение, а `now()` подставляет отметку времени в `created_at`. `RETURNING` выводит вставленную строку.

Теперь выведите список таблиц и посмотрите определение новой таблицы:

```text
\dt
\d terminal_notes
\d+ terminal_notes
```

Вариант с `+` запрашивает дополнительные подробности. Большинство команд, перечисляющих объекты, принимают и шаблон имени, так что `\dt terminal*` сузит список.

## Управление выводом и справка

Широкие строки бывает удобнее читать в вертикальном виде. Позвольте `psql` самому включать расширенный вывод, когда это нужно, и показывать время выполнения каждого SQL-оператора:

```text
\x auto
\timing on
```

Обе настройки действуют до конца текущего сеанса `psql`. Замер времени отключается командой `\timing off`, а обычный табличный вывод возвращается командой `\x off`.

Вместо того чтобы покидать терминал, пользуйтесь встроенной справкой:

```text
\?
\h
\h CREATE TABLE
```

`\?` описывает метакоманды psql. `\h` перечисляет SQL-команды, для которых доступна справка по синтаксису, а `\h CREATE TABLE` показывает справку по одной конкретной команде.

## Выполнение одной команды или SQL-файла

Для быстрой проверки из терминала используйте `-c`. `psql` выполнит всю SQL-строку и завершит работу:

```sh
psql -d postgresql_course -c 'SELECT current_database(), current_user;'
```

Чтобы выполнить файл, сохраните SQL-операторы в `lesson.sql` в текущем каталоге оболочки. Параметр `-f` выполнит его и сообщит об ошибках с номерами строк:

```sh
psql -d postgresql_course --set=ON_ERROR_STOP=on -f lesson.sql
```

`ON_ERROR_STOP` прекращает обработку файла после первой ошибки. В интерактивном сеансе то же поведение включают перед чтением файла:

```text
\set ON_ERROR_STOP on
\i lesson.sql
```

Эта настройка не отменяет операторы, которые уже успешно выполнились. Объединять изменения, которые должны либо пройти, либо не пройти вместе, позволяют транзакции; о них речь пойдёт позже.

## Завершение сеанса

Выйдите из клиента командой:

```text
\q
```

Она закрывает клиентское подключение и возвращает вас в оболочку macOS. Сервер PostgreSQL при этом не останавливается: служба Homebrew продолжит работать для следующих уроков.

## Практика

Подключитесь к локальной базе данных курса и командой `\conninfo` проверьте активную базу и роль. Включите замер времени, затем создайте и заполните небольшую таблицу:

```sql
DROP TABLE IF EXISTS practice_terminal_notes;

CREATE TABLE practice_terminal_notes (
  id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  body text NOT NULL
);

INSERT INTO practice_terminal_notes (body)
VALUES ('connect'), ('inspect'), ('query');
```

Выполните следующие задания, не выходя из `psql`:

1. Выведите только те таблицы, имена которых начинаются с `practice_`.
2. Покажите столбцы, значения по умолчанию, индексы и ограничения таблицы `practice_terminal_notes`.
3. С помощью встроенной справки откройте описание синтаксиса `INSERT`.
4. Включите автоматический расширенный вывод и выберите все строки таблицы.
5. Выйдите командой `\q`, а затем из оболочки macOS с помощью `psql -d postgresql_course -c` получите количество строк.

Задание выполнено, когда команда оболочки выведет `3`. Подключитесь снова и удалите таблицу командой `DROP TABLE practice_terminal_notes;`, чтобы упражнение можно было повторить.
